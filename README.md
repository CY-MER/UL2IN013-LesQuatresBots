## Description du projet
Ce projet consiste à concevoir un mini-robot autonome capable de se déplacer dans un environnement en évitant des obstacles et de tracer un carré . 
Une simulation 2D a été développée avec Pygame afin de visualiser le comportement du robot et tester les différentes stratégies.  

## User Story
En tant qu'utilisateur, je souhaite un robot capable d’exécuter des déplacements prédéfinis, de détecter et éviter des obstacles, afin d’interagir efficacement avec son environnement.

## Objectifs
- Tracer un carré 
- Éviter les obstacles
